# My Frist Project (Surge protector simulator)

i made this project for surge protector. its very simple but i hope it works. if u want to run it follow my steps below because i spent 2 hours figuring it out lol.

##  How to open and run (PLZ FOLLOW CAREFULLY)

### Step 1: Open the file
1. Go to the folder called `project files`.
2. Then go inside `Protesus Simulation` folder (i think i spelled it wrong but its okay).
3. Find the file named `surgeprotector.pdsprj`.
4. **Double click it** to open in Proteus 8.13. (Make sure u have Proteus 8.13 or it might crash!!)

## Step 2: Put the code in the chip (Important!!)
1. Look for the big chip named **Atmega328PU** on the screen.
2. **Double click** on it. A window will pop up.
3. Look for the file upload section.
4. Click browse and go to the `src` folder.
5. Select the **`main.hex`** file. 
6. Click OK.

## Step 3: Run it!
* Just click the big **Play** button at the bottom left corner to start the simulation!
